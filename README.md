# MongoDB Basic Assignment

This repository contains the MongoDB Basic training assignment completed using MongoDB and `mongosh`.

## Files

- `mongodb-basic-assignment.js` – MongoDB commands for Tasks 1–6, covering database setup, CRUD operations, queries, updates, indexing, and aggregation.
- `answers.md` – Answers for Task 7 MongoDB fundamentals MCQs.

## Topics Covered

- Database and collection creation
- CRUD operations
- Query and update operators
- Indexing
- Aggregation
- MongoDB fundamentals
